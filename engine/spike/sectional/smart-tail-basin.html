Why every cliff is the same cliff

Plotting all 36 rows against the scalar they are scored from collapses the five families onto one curve — and the elbow sits exactly at the knot. The frozen pressure map is piecewise-linear in the proxy, and its slope jumps from 0.02617 to 0.70888 at proxy 0.180789. Every large Cd step in this experiment is a row crossing that line.

The basin's edge is a calibration feature

The baseline sits at proxy 0.161170 — 10.9% below the knot. A modest geometry change that pushes the proxy past 0.180789 produces a disproportionate Cd jump, because the map is 27× steeper on the far side. This is the same knot spec 81.4 already flagged for a 3.3% provenance discrepancy: it computes 0.186851 through the harness path while being the knot at 0.180789. Nothing was moved.

The baseline is not the best-supported point

At the baseline the authored and hulled representations differ by 40.3% in proxy while Cd moves 7.5% — spec 78.4's “most dangerous” case, where agreement is a property of a flat map region rather than of the geometry. Every earlier fairing pickup (ATTACH 0.60–0.75) scores 6.6–7.8% lower on robust geometry, Δproxy 0.0–4.9%, within the same class.

The prediction that was frozen first

Before the terminal-radius family was built, the classifier crossing was pre-registered between rTip/ra 0.20 and 0.28, derived from the frozen threshold: a base trips it once rTip exceeds rMax·√TAU = 25.27 m = 0.2751 ra. It flipped exactly there, fired by trigger (b), terminal base 0.0574 against TAU 0.05. The measured base fraction runs 10.8% above analytic — the same fixed-cell raster over-count recorded in spec 83.3, at the same magnitude, in a second independent family.

Estimator-response experiment, not aerodynamic validation. No statement about the real drag of any shape follows from it.
